Sgtin генератор (калькулятор) - это программа для вычисления SGTIN96 ключа, необходимого для индивидуализации контрольного идентификационного знака (КИЗ), выданного госзнаком для маркировки мехового изделия

Чтобы сгенерировать ключ sgtin96 требуется ввести в соответствующие поля GTIN 46ХХХХХХХХХХХ и TID (серийный номер КИЗ) E2003ХХХХХХХХХХХХХХ, который находится в расширенной информации КИЗ в разделе коды маркировок в личном кабинете Честный знак

    Что такое SGTIN96?

    SGTIN96 - это уникальный ключ для каждой шубы, состоящий из последовательности нулей и единиц, обозначающий единственную в своём роде единицу

    Какое оборудование нужно для индивидуализации (маркировки) меховых изделий?

    Согласно постановлению правительства РФ, участник маркировки, который заказывает неиндивидуализированные КИЗ у ГОЗНАКа, обязан самостоятельно вносить SGTIN96 в RFID-метку, которая находится в КИЗе. Для этого потребуется оборудование, которое поддерживает запись в RFID-метку диапазона UHF (860—960 МГц)

    Как из SGTIN96 получить КИЗ?

    Номер киз не участвует в процессе формирования SGTIN96. Поэтому вычислить номер киз, который присвоил ГОЗНАК - напрямую нельзя
